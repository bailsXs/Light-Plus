# Light+

Light+ is a NeoForge mod that adds luminous concrete blocks for decorative lighting.

## Features

- Seven luminous concrete colours
- Maximum light level of 15
- Quick to break by hand
- Separate Light+ creative tab
- Survival crafting recipes
- Matching vanilla concrete textures

## Available colours

- White
- Red
- Blue
- Green
- Black
- Yellow
- Gray

## Requirements

- Minecraft 26.1.2
- NeoForge 26.1.2

## Installation

1. Install NeoForge for Minecraft 26.1.2.
2. Download the Light+ JAR.
3. Place the JAR in your `mods` folder.
4. Install the mod on both the server and client when playing multiplayer.
